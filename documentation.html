Pleiotropy Decomposition Pipeline

This documentation provides information on our own custom pipeline to dissect pleiotropy. Using only GWAS summary statistics as input, this pipeline runs a total of 8 different methods to better understand the shared and distinct components of multiple GWAS.

GWAS tutorial on DNAnexus

This documentation provides a step-by-step guide on the use of DNAnexus, also called UK Biobank Research Analysis Platform (UKB-RAP), to perform a GWAS on the UK Biobank data. It is directed to beginners and new users of the platform, and contains all of the tools necessary to understand and correctly use the platform. The goal is to easily aprehend the use of this new platform to then gain confidence when running analyses.
